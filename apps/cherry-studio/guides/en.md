# Cherry Studio install guide (short)

> The full pictorial tutorial lives on the aibox.im /apps/cherry-studio/ page
> (generated from this repo).
> Tagline: **"Installed until it works."**

## 1. Health check (automatic)
AiBOX checks your machine first. Cherry Studio is self-contained —
no Node.js required.

## 2. Route selection (automatic)
- **International network**: official GitHub Releases (direct).
- **Mainland China**: ghfast / gh-proxy gateway channels, automatic fallback.

## 3. Install (one click)
Download with SHA256 verification, then silent install
(Windows x64/ARM64: NSIS to `%LOCALAPPDATA%\Programs\Cherry Studio`;
macOS: Intel / Apple Silicon dmg copied to `/Applications`). No admin rights.

## 4. Add your key (the only step you do)
Pick a provider: OpenRouter (recommended) / Anthropic / OpenAI / Google.
Paste the key in Cherry Studio's provider settings and you are ready to chat.

## 5. Verify (automatic)
We check the installed version — "Installed. It really works."
