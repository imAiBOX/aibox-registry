# Cherry Studio 安装引导（简版）

> 完整图文教程见官网 /apps/cherry-studio/（与本页同源）。
> 口号：**装到能用为止。**

## 1. 体检（自动）
AiBOX 会先检查你的电脑。Cherry Studio 自带运行时——不需要 Node.js。

## 2. 选路线（自动）
- **国际网络**：GitHub Releases 官方直连。
- **中国大陆**：走 ghfast / gh-proxy 加速网关，失败自动回落直连。

## 3. 安装（一键）
自动下载 + SHA256 校验 + 静默安装（Windows x64/ARM64 装到
`%LOCALAPPDATA%\Programs\Cherry Studio`；macOS 按机型选 Intel/Apple Silicon
dmg 拷贝到 `/Applications`）。全程无需管理员权限。

## 4. 填 Key（你只需要做这一步）
四选一：OpenRouter（推荐）/ Anthropic / OpenAI / Google。
在 Cherry Studio 的模型服务商设置里粘贴 Key，即可开始聊天。

## 5. 验证（自动）
检查已安装版本——「装好了。它真的能用。」
