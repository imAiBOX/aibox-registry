# Jan install guide (short)

> The full pictorial tutorial lives on the aibox.im /apps/jan/ page
> (generated from this repo).
> Tagline: **"Installed until it works."**

## 1. Health check (automatic)
AiBOX checks your machine first. Jan is self-contained —
no Node.js required.

## 2. Route selection (automatic)
- **International network**: official GitHub Releases (direct).
- **Mainland China**: ghfast / gh-proxy gateway channels, automatic fallback.

## 3. Install (one click)
Download with SHA256 verification, then silent install
(Windows x64/ARM64: NSIS to `%LOCALAPPDATA%\Jan`; macOS: universal dmg
copied to `/Applications`, one file for Intel and Apple Silicon).

## 4. Choose your models (the only step you do)
Run local open-source models (free, offline), or connect a key:
OpenRouter (recommended) / Anthropic / OpenAI / Google.

## 5. Verify (automatic)
We check the installed version and the local API at `http://localhost:1337`
— "Installed. It really works."
